Installing from the Registry adds an information page only; it does not resize any images. To get R2 Image Variants, install the native plugin from npm with `npm install emdash-plugin-r2-variants` and register it in `plugins: []` in `astro.config.mjs`. Full setup, including the Cloudflare bindings it needs: [README](https://github.com/rjstech2020/emdash-plugin-r2-variants#readme).
